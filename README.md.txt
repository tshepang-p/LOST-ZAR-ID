FIND MY ID


1. SUBMITTING
	If a person has found a lost ID, they can submit it in the submit form. The
	submit page should have slots to enter data such as the names on the ID, and
	the ID number as well. The same form should also have spaces for the user to
	put in their contact details such as their phone number and email address. The
	purpose is for the person searching the ID to be able to find the person who
	has their ID then they can make arrangements to collect their ID card.

2. SEARCHING
	The search area should have the place to search for the id number and the button
	to initate the search process. If no data has been found, the page should display
	a not found search result. If found, it should display all the result.

3. ABOUT
	The about page should display what the page is about, the developers and the purpose
	of the website. It should also display the terms and conditions that people are automatically
	adhearing to when using the platform
